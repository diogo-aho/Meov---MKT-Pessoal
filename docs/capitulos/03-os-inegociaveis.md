# Capítulo 3 · Os Inegociáveis

**Movimento I: Raiz** · **Quando:** imersão

> Valor escolhido de lista pronta você esquece numa semana. Valor descoberto pelo que te dá repulsa é seu de verdade.

## Por que este capítulo existe

Todo mundo diz que valoriza "ética, excelência e compromisso". Isso não diferencia ninguém. Quando a pessoa lista o que a marca rejeita, o valor aparece sozinho do outro lado. O Método Meov vai um passo além: todo valor precisa mostrar **como aparece no conteúdo**. Se não aparece, não é valor de marca.

## Perguntas para conduzir

- O que você vê na sua área e pensa "eu nunca faria isso"?
- Que tipo de profissional te dá vergonha alheia?
- Que promessa do seu mercado você acha desonesta?
- Que atitude de cliente ou de colega te tira do sério?

Para cada resposta:
1. **O que minha marca rejeita** → **o valor que isso revela**
2. **Como esse valor aparece na prática**, no conteúdo e no atendimento

Ao final, escolha os **3 inegociáveis** principais.

## O que vai para o Brandbook

| Campo | Descrição |
|---|---|
| `rejeicoes` | Lista de pares "rejeito → valor" (de 3 a 6) |
| `inegociaveis` | Os 3 valores principais |
| `inegociaveis_na_pratica` | Para cada um, como ele aparece no conteúdo e no atendimento |

## Exemplo: Marina

| O que minha marca rejeita | Valor que isso revela | Como aparece |
|---|---|---|
| Advogado que fala juridiquês para parecer inteligente | **Clareza** | Todo conteúdo termina com "na prática, isso significa ___" |
| Promessa de "zerar imposto" | **Honestidade técnica** | Sempre mostra o risco junto com a oportunidade |
| Escritório que some depois de assinar o contrato | **Presença** | Mostra bastidores de acompanhamento de caso, sem expor o cliente |
| Tratar empresário como suspeito | **Respeito** | Nunca usa medo ou ameaça como gancho de conteúdo |

**Inegociáveis:** clareza, honestidade técnica e respeito.

## Armadilhas

- Valores abstratos sem prática. "Transparência" sozinha não serve. Como ela aparece num post?
- Rejeições que atacam pessoas específicas. A marca rejeita comportamentos, não nomes.
- Inegociáveis demais. Mais de três dilui.

## Toque Meov

Este capítulo dá permissão para o cliente ter opinião. Muitos especialistas aprenderam a ser neutros para não se queimar. Lembre que ter posição, com respeito, é o que faz a tribo se reconhecer.
