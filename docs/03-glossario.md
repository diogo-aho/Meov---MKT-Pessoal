# Glossário do Método Meov

| Termo | Significado |
|---|---|
| **Raiz, Território, Voz, Movimento** | Os 4 movimentos do método: quem sou, onde me posiciono, como me expresso, como apareço com constância. |
| **Espelho** | Diagnóstico do ponto de partida: presença digital atual + como os outros veem o cliente. |
| **Linha de base** | Números e percepções registrados no Espelho, usados para medir a evolução no semestre. |
| **Chamado** | O desejo honesto por trás da marca pessoal. |
| **Travas** | Medos e crenças que impedem o cliente de se expor. |
| **Frase de permissão** | Frase que o cliente se dá para atravessar as travas: "Eu me permito ___, mesmo que ___." |
| **Norte** | A bússola de propósito: 5 pilares sintetizados em uma frase. |
| **O que me inquieta (a agulha)** | O 5º pilar: o incômodo que revela os valores e aponta o rumo. |
| **Frase-norte** | Síntese do propósito em uma linha. O porquê que sustenta quando a motivação some. |
| **Inegociáveis** | Valores descobertos pelo contraste: o que rejeito → o valor que isso revela → como aparece no conteúdo. |
| **Travessia** | A história real do cliente: a virada verdadeira, sem mentira de guru. |
| **Banco de histórias** | Momentos curtos e reais que viram conteúdo. |
| **Banco de provas** | Evidências que sustentam a autoridade: números, casos, depoimentos, credenciais. |
| **Tribo** | Quem a marca quer atrair e com quem quer se conectar. Audiência assiste, tribo age. |
| **Mantra de posicionamento** | "Eu ajudo [quem] a [resultado] através de [método]." |
| **Tabuleiro** | Mapa do mercado em eixos com dois polos. Base de 5 eixos, personalizada por nicho. |
| **Espaço em branco** | A brecha do tabuleiro que ninguém ocupa direito. É ali que a marca crava bandeira. |
| **Código** | O sistema de crença da marca: credo, léxico, rituais e assinatura. |
| **Credo** | O que a marca defende, em uma frase que caberia numa camiseta. |
| **Léxico** | Palavras e bordões que são marca registrada verbal, mais as palavras que a marca nunca usa. |
| **Rituais** | Séries e formatos fixos que criam hábito na tribo. |
| **Imagem** | Tom de voz, cor, tipografia, direção de foto e vídeo, moodboard. |
| **Escada de valor** | O caminho do conteúdo gratuito até a oferta premium. |
| **Chamada principal** | A ação que a marca pede para a tribo, repetida em todos os canais. |
| **Territórios** | Os 3 grandes temas sobre os quais o cliente fala com constância. |
| **Pautas-semente** | Primeiras ideias concretas de conteúdo dentro de cada território. |
| **Dia de gravação** | Encontro mensal de produção audiovisual Meov + cliente. |
| **Ciclo** | Um semestre de execução, que termina em revisão e atualização do Brandbook. |
